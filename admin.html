Setup Guide
One-time, takes 2 minutes
  • 1
    Open the Google Sheet
    Click here to open →
    Sign in with the Google account that owns the sheet.
  • 2
    Open Apps Script
    In the sheet menu: Extensions → Apps Script
    Delete any existing code in the editor.
  • 3
    Paste the Script
    Copy the full code below and paste it into the editor. Press Ctrl + S to save.
  • 4
    Deploy as Web App
    Click Deploy → New Deployment
    Type: Web App
    Execute as: Me
    Who has access: Anyone
    Click Deploy → Authorize → copy the URL.
  • 5
    Paste URL & Connect
    Paste the URL in the field on the left, click Save & Test Connection. Badge turns green = ready!
