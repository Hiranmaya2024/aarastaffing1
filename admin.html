Setup Guide
One-time, 2 minutes
  • 1
    Open the Google Sheet
    Click here to open →
  • 2
    Open Apps Script
    Extensions → Apps Script — delete any existing code in the editor.
  • 3
    Paste & Save
    Copy the full code below, paste it into the editor, press Ctrl + S to save.
  • 4
    Deploy as Web App
    Deploy → New Deployment
    Type: Web App
    Execute as: Me
    Who has access: Anyone
    Click Deploy → Authorize when prompted → Copy the URL.
  • 5
    Paste URL & Connect
    Paste the URL in the field on the left → click Save & Test Connection. Green = fully ready for reading and writing!
